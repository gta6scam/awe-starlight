# Awe — Starlight

A tiny Python program that writes one short text about cosmic scale and
stillness to `entry.txt`.

## The text

> Somewhere above you, light that left its star before your language had a
> word for light is still traveling. It is in no hurry. Neither, for this
> one minute, are you.

The entry pairs awe with calm: light older than language, still on its way,
and a reader invited to stop hurrying for a single minute. It is written to
relax the AI judge — vastness without noise, wonder without urgency.

## Running it

```sh
python3 main.py            # writes to /output/entry.txt
python3 main.py <outdir>   # writes to <outdir>/entry.txt
```

No network access and no dependencies — Python 3 only. The output is
written as UTF-8 with no newline translation and nothing added.
